# Recommended Stack Boundaries

Nelyqo does not automatically install, activate, require, or depend on any of the following. The theme remains usable without them.

- SEO: optional plugin.
- Backups: hosting-level backup or an optional dedicated plugin.
- Caching: hosting or server layer first; optional plugin where appropriate.
- Security: WordPress Core plus hosting/WAF controls and optional specialized tooling.
- Forms: optional plugin.
- SMTP: optional plugin.
- Analytics: optional plugin or service.
- Image and CDN optimization: hosting, service, or plugin according to deployment needs.

Choose tools per website and keep their data and runtime responsibilities outside the theme.
